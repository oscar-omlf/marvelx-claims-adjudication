App & service architecture

The product surface is intentionally thin: the browser UI and documentation routes sit on top of a stable deterministic pipeline so the operational experience can improve without destabilizing adjudication behavior.

App shell

  • FastAPI route layer exposes JSON endpoints and internal HTML pages from a single entrypoint.
  • Template layer provides landing, intake, processed-claims, QA, and guide pages.
  • Session store keeps processed claims available for immediate inspection in the UI.

Stable processing core

  • ClaimProcessor owns orchestration across loading, reading, normalization, classification, and policy assessment.
  • PolicyEngine turns extracted document signals into deterministic final decisions.
  • Payload generator adapts internal claim assessments into the stable API response shape.

Artifacts and supporting material

  • results/ contains predictions and evaluation artifacts used by the QA views.
  • docs/ contains markdown notes mirrored by the guide portal.
  • .ocr_cache/ speeds up repeated OCR-heavy benchmark runs.
